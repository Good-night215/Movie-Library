# 🎬 Movie Library

Личная кинотека — GUI-приложение для хранения и управления коллекцией фильмов.

---

## 📋 Описание

Приложение позволяет:
- ✅ Добавлять фильмы с указанием названия, жанра, года и рейтинга
- ✅ Просматривать все фильмы в виде таблицы
- ✅ Фильтровать фильмы по жанру и году
- ✅ Удалять фильмы из коллекции
- ✅ Автоматически сохранять данные в JSON-файл
