# 🎬 Movie Library

Личная кинотека — GUI-приложение для хранения и управления коллекцией фильмов.

---

## 📋 Описание

Приложение позволяет:
- ✅ Добавлять фильмы с указанием названия, жанра, года и рейтинга
- ✅ Просматривать все фильмы в виде таблицы
- ✅ Фильтровать фильмы по жанру и году
- ✅ Удалять фильмы из коллекции
- ✅ Автоматически сохранять данные в JSON-файл

## 📦 Требования

### Версия Python
- **Python 3.6** или выше
- Рекомендуется Python 3.8+

### Зависимости
Все используемые модули входят в **стандартную библиотеку Python**:

| Модуль | Описание |
|--------|----------|
| `tkinter` | Графический интерфейс (встроен) |
| `json` | Работа с JSON файлами (встроен) |
| `os` | Работа с файловой системой (встроен) |
| `unittest` | Тестирование (встроен) |

> ⚠️ **Примечание:** На некоторых Linux-системах tkinter может требовать отдельной установки:
> ```bash
> # Ubuntu/Debian
> sudo apt-get install python3-tk
> 
> # Fedora
> sudo dnf install python3-tkinter
> 
> # macOS (обычно предустановлен)
> brew install python-tk
> ```
